# Локален AI асистент + sd-server

Редактирана версия на предоставения Flask файл. Чатът използва същия llama.cpp адрес, модел, системен prompt и обработка на отговора.

## Стартиране

От папката с app.py и requirements.txt:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py.bak
```

Отворете http://localhost:5005. llama.cpp трябва да работи на localhost:8080, а sd-server — на 127.0.0.1:8081, на същата машина като Flask.

## Изображения

Prompt, negative prompt, steps (20), CFG (3.5), seed (-1 = случаен), init image и strength (0.7). Размерът е фиксиран на 512×512, batch е 1. Init image превключва към img2img. Резултатът има PNG download. При тесен екран чатът се премества под панела.

Flask препраща към /sdapi/v1/txt2img или /sdapi/v1/img2img. Negative prompt се подава към поддържащия го API; ефектът зависи от модела. Изчакването за отговор е до 30 минути. При timeout сървърът може все още да генерира. Защитата срещу едновременни заявки е за един Flask процес. Debug режимът е изключен.

## Проверка

Проверени са Python и JavaScript синтаксисът, зареждането на страницата, маршрутите и параметрите за txt2img/img2img, валидацията, грешката при недостъпен сървър, блокирането на паралелни заявки и отговорът на чата с подменени backend отговори. При проверката порт 8081 не беше достъпен, затова реално генериране не е изпълнявано.
